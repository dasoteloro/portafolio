# Portafolio — Daniel Sotelo Rodríguez

Estadístico · Analista de Datos y Business Intelligence. Cinco casos con **tableros** en Power BI y web,
**informes de resultados** y **manuales de uso**, que se recorren en el sitio página por página, sin descargar nada.

🔗 **Sitio:** https://dasoteloro.github.io/portafolio/

| Caso | Sector | Entregables |
|---|---|---|
| **Tándem** · pauta digital | Marketing | Tablero Power BI · presentación de hallazgos · manual de uso |
| **FiduciaTrust** · estudio CX | Finanzas | Informe de 73 láminas · tablero web |
| **Maré Serena** · reservas de un resort | Turismo | Tablero Power BI · manual de uso · documentación técnica |
| **Óptica Vértice** · estudio CX | Retail | Informe de 103 láminas · tablero web |
| **Classic Models** · ventas | Ventas B2B | Tablero Power BI · manual de uso |

Enlace directo a un caso y entregable: `#<caso>/<tipo>`, por ejemplo
`https://dasoteloro.github.io/portafolio/#fiduciatrust/presentacion` o `#mare-serena/tecnica`.

## Estructura
```
index.html                 la landing con el visor
assets/casos.js            los casos, sus vistas (tablero, presentación, manual, técnica) y textos
assets/pantallas/<caso>/   capturas de cada página de los tableros
assets/entregables/<caso>/ láminas y páginas de manuales elegidas (JPG 1600 px)
descargas/<caso>/          .pbix, manuales y presentación en PDF
fiduciatrust/, vertice/    páginas de caso con vista previa para LinkedIn + dashboard.html + informe.pdf
```
Los enlaces antiguos (`/fiduciatrust/` y `/vertice/`) siguen funcionando.

## Aviso
Las empresas de los casos son **ficticias**. Los datos son públicos (Hotel Booking Demand, base de práctica de
ventas, base de práctica de pauta digital) o fueron creados para el portafolio.
