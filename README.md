## Proyectos

### Estudio CX Relacional — FiduciaTrust *(demo)*
Estudio de experiencia de cliente para una fiduciaria. **Empresa y datos 100% ficticios**, creados
para mostrar el alcance del trabajo. Incluye:

- **Pipeline en Python** que genera y procesa las encuestas y calcula indicadores (**NPS, CSAT,
  voz del cliente**), con comparativo interanual y segmentación por línea de negocio.
- **Dashboard web interactivo autocontenido** (un solo archivo HTML, sin licencias ni servidor):
  [`fiduciatrust/index.html`](fiduciatrust/index.html)
- **Informe ejecutivo** de 73 láminas con análisis y recomendaciones:
  [`fiduciatrust/informe.pdf`](fiduciatrust/informe.pdf)

**Stack:** Python (pandas), JavaScript, HTML/CSS, automatización con IA.
