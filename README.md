## Proyectos

### Estudio CX Relacional — FiduciaTrust *(demo)*
Estudio de experiencia de cliente para una fiduciaria. **Empresa y datos 100% ficticios**, creados
para mostrar el alcance del trabajo. Incluye:

- **Pipeline en Python** con el que genero y proceso las encuestas y calculo indicadores (**NPS,
  CSAT, voz del cliente**), con comparativo interanual y segmentación por línea de negocio.
- **Dashboard web interactivo autocontenido** (un solo archivo HTML, sin licencias ni servidor):
  https://dasoteloro.github.io/portafolio/fiduciatrust/
- **Informe ejecutivo** de 73 láminas con análisis y recomendaciones:
  https://dasoteloro.github.io/portafolio/fiduciatrust/informe.pdf

**Stack:** Python (pandas), JavaScript, HTML/CSS, automatización con IA.

### Estudio CX — Óptica Vértice *(demo)*
Estudio de experiencia de cliente para una cadena de ópticas: 820 encuestas, dos mediciones y
cinco regionales. **Empresa y datos 100% ficticios**. Lo que lo distingue del anterior:

- **Cadena de valor**: una matriz de importancia contra calificación que ordena por cuál atributo
  conviene empezar. La importancia no la infiere un modelo: el cliente menciona sus tres factores
  decisivos, los ordena y los califica, y la gráfica cruza ese peso con la nota que le da a la marca.
- **Dashboard web interactivo autocontenido**, con el cruce por segmento de negocio y por regional:
  https://dasoteloro.github.io/portafolio/vertice/
- **Informe ejecutivo** de 103 láminas con hallazgos, conclusiones y focos de acción:
  https://dasoteloro.github.io/portafolio/vertice/informe.pdf

**Stack:** Python (pandas), JavaScript + SVG, Node/pptxgenjs, IA para clasificación de respuestas
abiertas y redacción del análisis.
